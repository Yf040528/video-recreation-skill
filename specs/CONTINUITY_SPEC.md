# Continuity Specification
Create a master once for every recurring identity. For every shot, bind only masters whose presence is true. QA recurring elements against the master reference, not merely against the immediately previous generated frame.

Hard continuity dimensions include product geometry/material/color placement, subject/hand identity when specified, clothing material/tone/cuff, and recurring environment anchors when explicitly locked. Allowed variation should be declared separately (pose, camera, lighting, background, etc.).
