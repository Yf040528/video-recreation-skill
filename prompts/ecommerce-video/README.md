## 示例：护肤 · 痛点开场

```text
9:16 竖屏，约 15 秒。0–3 秒：镜子前看到脸上干燥起皮、暗沉，手指摸脸皱眉，画面上方留出标题位置；3–8 秒：【精华 / 面霜 / 面膜】登场，取适量涂抹在脸颊，指腹打圈轻轻推开、吸收；8–12 秒：皮肤水润透亮有光泽，侧脸在光下泛出自然光泽；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 提示词写法要点

1. **比例和时长**：抖音 / 视频号用 9:16 竖屏，单段 5–15 秒。
2. **时间分段**：开头 3 秒是钩子，决定完播率。
3. **主体**：人物外貌、产品名称和关键外观。
4. **动作**：拿起、涂抹、倒出、转身，越具体越好。
5. **镜头**：推近、拉远、环绕、平移、微距特写。
6. **光线和风格**：自然光、棚拍柔光、暖色、vlog 质感。
7. **合规**：保健、护肤、按摩类不要写治疗功效；配乐用有授权的音乐。
