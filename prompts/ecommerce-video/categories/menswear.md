# 男装带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：早上出门随便套件衣服，显得邋遢没精神，画面上方留出标题位置；3–8 秒：【衬衫 / 夹克 / 卫衣 / 裤子】登场，穿上后整理领口、袖口，对镜看效果；8–12 秒：整体干净利落有型，走路自信；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：面料纹理、拉链、口袋和走线的特写；随后依次展示三个卖点，每个约 3 秒：①版型挺括 ②面料质感 ③细节做工与多场景搭配；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：穿旧T恤显得随意邋遢；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：换上后精神利落、有型（同机位换装转场）；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在城市街头 / 办公室 / 健身房门口中，20–40 岁男生自然地穿上后整理领口、袖口，对镜看效果，镜头从中景慢慢推近到【衬衫 / 夹克 / 卫衣 / 裤子】；拉链拉上的声音、布料抖开的声音；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【衬衫 / 夹克 / 卫衣 / 裤子】的包装，依次取出包装和衣服平铺并整齐摆放；随后上手穿上后整理领口、袖口，对镜看效果，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。20–40 岁男生形象的博主正对镜头半身中景，手持【衬衫 / 夹克 / 卫衣 / 裤子】，自然地说：「【台词：直男穿搭不踩雷，一件搞定通勤和约会】」，边说边展示版型挺括；表情真诚有感染力，口型自然；背景是城市街头 / 办公室 / 健身房门口，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【衬衫 / 夹克 / 卫衣 / 裤子】在画面中央弹出并缓慢旋转，周围是礼盒、彩带和闪光粒子；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
