# 户外露营带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：周末宅在家无聊，想出去玩又怕麻烦，画面上方留出标题位置；3–8 秒：【帐篷 / 露营装备 / 登山用品】登场，几分钟搭好帐篷 / 摆好装备；8–12 秒：在山野 / 湖边享受惬意时光；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：面料、支架、收纳尺寸的细节特写；随后依次展示三个卖点，每个约 3 秒：①快速搭建 ②材质与防护（防水防晒） ③收纳便携；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：以前出游装备繁琐；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：现在几分钟就搭好营地；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在湖边草地 / 山林营地中，户外爱好者 / 周末出游家庭自然地几分钟搭好帐篷 / 摆好装备，镜头从中景慢慢推近到【帐篷 / 露营装备 / 登山用品】；风吹帐篷的沙沙声、篝火声；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【帐篷 / 露营装备 / 登山用品】的包装，依次取出收纳袋和全套装备摊开并整齐摆放；随后上手几分钟搭好帐篷 / 摆好装备，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。户外爱好者 / 周末出游家庭形象的博主正对镜头半身中景，手持【帐篷 / 露营装备 / 登山用品】，自然地说：「【台词：周末说走就走的露营装备】」，边说边展示快速搭建；表情真诚有感染力，口型自然；背景是湖边草地 / 山林营地，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【帐篷 / 露营装备 / 登山用品】在画面中央弹出并缓慢旋转，周围是篝火和星空灯串；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
