# 箱包带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：出门东西太多塞不下，包被撑得变形，画面上方留出标题位置；3–8 秒：【包包 / 双肩包 / 行李箱】登场，依次把手机、钱包、电脑、水杯等放进包里，拉上拉链背起；8–12 秒：包型依旧挺括，人物背着走出门，自信从容；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：皮质纹理、五金、拉链和内部分层的特写；随后依次展示三个卖点，每个约 3 秒：①包型与颜值 ②大容量分区收纳 ③上身效果；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：旧包塞满后变形杂乱；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：新包整齐收纳、外形挺括；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在通勤地铁站 / 机场 / 街头中，通勤女生 / 商务人士 / 旅行爱好者自然地依次把手机、钱包、电脑、水杯等放进包里，拉上拉链背起，镜头从中景慢慢推近到【包包 / 双肩包 / 行李箱】；拉链顺滑拉动的声音、磁扣吸合声；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【包包 / 双肩包 / 行李箱】的包装，依次取出防尘袋、包身和配件并整齐摆放；随后上手依次把手机、钱包、电脑、水杯等放进包里，拉上拉链背起，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。通勤女生 / 商务人士 / 旅行爱好者形象的博主正对镜头半身中景，手持【包包 / 双肩包 / 行李箱】，自然地说：「【台词：能装下一整天的通勤包】」，边说边展示包型与颜值；表情真诚有感染力，口型自然；背景是通勤地铁站 / 机场 / 街头，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【包包 / 双肩包 / 行李箱】在画面中央弹出并缓慢旋转，周围是礼盒、彩带和闪光粒子；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
