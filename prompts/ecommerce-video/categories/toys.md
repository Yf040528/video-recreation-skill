# 儿童玩具带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：孩子一直盯着手机平板，家长发愁，画面上方留出标题位置；3–8 秒：【积木 / 益智玩具 / 遥控车】登场，孩子拆开玩具专注地拼搭 / 玩耍；8–12 秒：孩子开心地举起成品，和爸妈击掌；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：玩具零件、颜色和可动结构的特写；随后依次展示三个卖点，每个约 3 秒：①安全材质 ②玩法与互动性 ③益智 / 动手能力；镜头缓推、平移交替，明亮彩色背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：孩子盯着屏幕发呆；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：孩子专注动手、开心大笑；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在阳光明媚的客厅地毯上中，家长和 3–10 岁孩子自然地孩子拆开玩具专注地拼搭 / 玩耍，镜头从中景慢慢推近到【积木 / 益智玩具 / 遥控车】；积木拼接的咔哒声、孩子的笑声；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【积木 / 益智玩具 / 遥控车】的包装，依次取出包装盒和全部零件并整齐摆放；随后上手孩子拆开玩具专注地拼搭 / 玩耍，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。家长和 3–10 岁孩子形象的博主正对镜头半身中景，手持【积木 / 益智玩具 / 遥控车】，自然地说：「【台词：能让孩子放下手机的玩具】」，边说边展示安全材质；表情真诚有感染力，口型自然；背景是阳光明媚的客厅地毯上，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【积木 / 益智玩具 / 遥控车】在画面中央弹出并缓慢旋转，周围是彩色气球和彩带；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
