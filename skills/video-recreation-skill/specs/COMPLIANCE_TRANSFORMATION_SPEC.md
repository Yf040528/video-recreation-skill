# Compliance and Transformation Specification

Before recreation, record rights/usage constraints for source video, people/likeness, music, fonts, logos, products, and other protected assets when known. Flag uncertain rights for user review rather than assuming permission.

Recreation should produce meaningful transformation where the job calls for creative recreation. Evaluate difference across visual treatment, copy/dialogue, voice/audio, pacing/edit rhythm, environment/composition, and value proposition. Do not treat face/background swaps alone as sufficient transformation.

Final review should check for unwanted source branding/UI/watermarks, unauthorized likeness use where applicable, music/font licensing concerns, platform policy constraints, and excessive source similarity. This Skill does not promise platform approval or legal clearance; it records checks and blocks/flags according to configured policy.
