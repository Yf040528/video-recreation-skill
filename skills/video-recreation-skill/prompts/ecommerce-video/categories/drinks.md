# 饮品冲饮带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：下午犯困、无精打采，趴在桌上，画面上方留出标题位置；3–8 秒：【咖啡 / 茶饮 / 果汁 / 奶粉冲饮】登场，冲泡 / 打开瓶盖倒进加冰的杯子里；8–12 秒：喝一口后精神一振，人物满意微笑；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：液体倒入杯中、冰块碰撞、气泡上升的慢镜头；随后依次展示三个卖点，每个约 3 秒：①包装颜值 ②冲泡 / 倒出的画面 ③口感与提神效果；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：下午昏昏欲睡；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：喝完神清气爽、状态满格；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在阳光下的办公桌 / 户外野餐中，上班族 / 学生自然地冲泡 / 打开瓶盖倒进加冰的杯子里，镜头从中景慢慢推近到【咖啡 / 茶饮 / 果汁 / 奶粉冲饮】；冰块碰撞杯壁的叮当声、倒水声；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【咖啡 / 茶饮 / 果汁 / 奶粉冲饮】的包装，依次取出整箱包装和杯子并整齐摆放；随后上手冲泡 / 打开瓶盖倒进加冰的杯子里，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。上班族 / 学生形象的博主正对镜头半身中景，手持【咖啡 / 茶饮 / 果汁 / 奶粉冲饮】，自然地说：「【台词：打工人续命必备】」，边说边展示包装颜值；表情真诚有感染力，口型自然；背景是阳光下的办公桌 / 户外野餐，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【咖啡 / 茶饮 / 果汁 / 奶粉冲饮】在画面中央弹出并缓慢旋转，周围是冰块、水花和柠檬片；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
