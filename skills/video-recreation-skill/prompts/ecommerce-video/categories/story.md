# 故事情节带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 反转小剧情

```text
【场景】中，【人物 A】正在【做某事】，表情【平静 / 焦急】；【人物 B】突然出现，说出关键一句【台词】；镜头切到人物 A 的面部特写，表情从惊讶转为【微笑 / 恍然大悟】；整体电影感光影，镜头运动平稳，情绪推进自然。
```

## 2. 温情时刻

```text
傍晚暖色夕阳下，【人物】在【地点，如老街 / 阳台 / 公园长椅】上，【动作，如为家人披上外套 / 递上一杯热茶】；镜头缓慢推近，捕捉人物眼神和细微笑容；画面柔和，浅景深，背景虚化，氛围温暖治愈。
```

## 3. 悬念开场

```text
昏暗的【场景】里，镜头从【物件，如一封信 / 一部亮起的手机】的特写缓缓拉远，露出【人物】的背影；人物慢慢转身，表情【紧张 / 犹豫】；冷色调光线，轻微手持晃动感，营造悬念；结尾停在人物的眼神特写。
```
