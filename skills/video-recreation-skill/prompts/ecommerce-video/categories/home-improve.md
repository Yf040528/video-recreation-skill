# 家装灯具带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：房间昏暗、墙面老旧，没有氛围，画面上方留出标题位置；3–8 秒：【灯具 / 墙纸 / 地板 / 智能家居】登场，安装 / 打开产品，切换不同模式；8–12 秒：房间氛围感拉满，人物惬意坐下；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：材质、光线色温、安装结构的细节特写；随后依次展示三个卖点，每个约 3 秒：①外观与质感 ②效果演示（灯光 / 铺贴） ③安装简单；镜头缓推、平移交替，现代家居背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：改造前昏暗老旧；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：改造后温馨有氛围（同机位对比）；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在客厅 / 卧室中，装修 / 改造的家庭自然地安装 / 打开产品，切换不同模式，镜头从中景慢慢推近到【灯具 / 墙纸 / 地板 / 智能家居】；开关按下的清脆声；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【灯具 / 墙纸 / 地板 / 智能家居】的包装，依次取出包装和配件并整齐摆放；随后上手安装 / 打开产品，切换不同模式，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。装修 / 改造的家庭形象的博主正对镜头半身中景，手持【灯具 / 墙纸 / 地板 / 智能家居】，自然地说：「【台词：低成本让家变得高级】」，边说边展示外观与质感；表情真诚有感染力，口型自然；背景是客厅 / 卧室，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【灯具 / 墙纸 / 地板 / 智能家居】在画面中央弹出并缓慢旋转，周围是礼盒、彩带和闪光粒子；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
