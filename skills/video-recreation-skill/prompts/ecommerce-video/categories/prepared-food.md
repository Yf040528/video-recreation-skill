# 速食预制菜带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：加班到深夜饿了，不想做饭也不想点外卖，画面上方留出标题位置；3–8 秒：【自热锅 / 方便面 / 预制菜】登场，撕开包装、加热 / 冲泡，几分钟出锅；8–12 秒：热气腾腾的一大碗，人物大口吃得很满足；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：热气升腾、汤汁翻滚、筷子夹起面条 / 肉块的慢镜头；随后依次展示三个卖点，每个约 3 秒：①做法简单几分钟搞定 ②料包丰富、分量足 ③口感接近餐厅；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：饿着肚子翻冰箱什么都没有；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：几分钟做出一顿热乎的饭；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在深夜的出租屋 / 办公室 / 宿舍中，忙碌的上班族 / 宿舍党自然地撕开包装、加热 / 冲泡，几分钟出锅，镜头从中景慢慢推近到【自热锅 / 方便面 / 预制菜】；汤汁沸腾的咕嘟声、吸面的声音；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【自热锅 / 方便面 / 预制菜】的包装，依次取出整箱包装和全部料包摊开并整齐摆放；随后上手撕开包装、加热 / 冲泡，几分钟出锅，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。忙碌的上班族 / 宿舍党形象的博主正对镜头半身中景，手持【自热锅 / 方便面 / 预制菜】，自然地说：「【台词：懒人五分钟吃上大餐】」，边说边展示做法简单几分钟搞定；表情真诚有感染力，口型自然；背景是深夜的出租屋 / 办公室 / 宿舍，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【自热锅 / 方便面 / 预制菜】在画面中央弹出并缓慢旋转，周围是礼盒、彩带和闪光粒子；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
