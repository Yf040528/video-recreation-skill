# 耳机穿戴带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：地铁上噪音太大，听不清音乐，画面上方留出标题位置；3–8 秒：【耳机 / 音箱 / 智能手表】登场，戴上耳机 / 手表，开启降噪 / 运动模式；8–12 秒：世界瞬间安静，人物沉浸在音乐里 / 轻松运动；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：充电盒开合、耳机 / 表盘细节的特写；随后依次展示三个卖点，每个约 3 秒：①外观与佩戴 ②降噪 / 音质 / 功能演示 ③续航；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：通勤噪音嘈杂；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：开降噪后安静沉浸；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在地铁车厢 / 健身房 / 跑步道中，通勤族 / 运动爱好者自然地戴上耳机 / 手表，开启降噪 / 运动模式，镜头从中景慢慢推近到【耳机 / 音箱 / 智能手表】；充电盒磁吸开合声；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【耳机 / 音箱 / 智能手表】的包装，依次取出包装盒、本体和配件并整齐摆放；随后上手戴上耳机 / 手表，开启降噪 / 运动模式，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。通勤族 / 运动爱好者形象的博主正对镜头半身中景，手持【耳机 / 音箱 / 智能手表】，自然地说：「【台词：通勤路上的私人音乐厅】」，边说边展示外观与佩戴；表情真诚有感染力，口型自然；背景是地铁车厢 / 健身房 / 跑步道，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【耳机 / 音箱 / 智能手表】在画面中央弹出并缓慢旋转，周围是礼盒、彩带和闪光粒子；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
