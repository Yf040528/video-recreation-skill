# 护肤带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：镜子前看到脸上干燥起皮、暗沉，手指摸脸皱眉，画面上方留出标题位置；3–8 秒：【精华 / 面霜 / 面膜】登场，取适量涂抹在脸颊，指腹打圈轻轻推开、吸收；8–12 秒：皮肤水润透亮有光泽，侧脸在光下泛出自然光泽；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：膏体 / 精华液从瓶口滴落、在手背拉丝推开的微距质地；随后依次展示三个卖点，每个约 3 秒：①瓶身设计与成分标签 ②质地清透好吸收 ③上脸后的水光感；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：上脸前肤色暗沉、干燥起皮；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：上脸后水润透亮、细腻有光泽；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在明亮的浴室梳妆台中，25–35 岁女生自然地取适量涂抹在脸颊，指腹打圈轻轻推开、吸收，镜头从中景慢慢推近到【精华 / 面霜 / 面膜】；按压泵头的清脆声、精华在皮肤上迅速吸收；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【精华 / 面霜 / 面膜】的包装，依次取出瓶身、说明书和赠品小样并整齐摆放；随后上手取适量涂抹在脸颊，指腹打圈轻轻推开、吸收，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。25–35 岁女生形象的博主正对镜头半身中景，手持【精华 / 面霜 / 面膜】，自然地说：「【台词：换季脸干到起皮？这瓶我回购第三次了】」，边说边展示瓶身设计与成分标签；表情真诚有感染力，口型自然；背景是明亮的浴室梳妆台，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【精华 / 面霜 / 面膜】在画面中央弹出并缓慢旋转，周围是礼盒、彩带和闪光粒子；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
