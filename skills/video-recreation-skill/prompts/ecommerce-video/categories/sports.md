# 运动健身带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：在家想运动却不知道从哪开始，坐着发呆，画面上方留出标题位置；3–8 秒：【瑜伽垫 / 健身器材 / 运动服】登场，铺开 / 拿起器材开始锻炼；8–12 秒：动作标准有活力，汗水和笑容；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：材质纹理、防滑面、器材结构的特写；随后依次展示三个卖点，每个约 3 秒：①材质与做工 ②实际锻炼演示 ③收纳便携；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：以前久坐不动；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：现在在家也能高效锻炼；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在明亮的客厅 / 健身房中，健身爱好者 / 想变瘦的人自然地铺开 / 拿起器材开始锻炼，镜头从中景慢慢推近到【瑜伽垫 / 健身器材 / 运动服】；器材碰撞的声音、呼吸声；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【瑜伽垫 / 健身器材 / 运动服】的包装，依次取出包装和全部配件并整齐摆放；随后上手铺开 / 拿起器材开始锻炼，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。健身爱好者 / 想变瘦的人形象的博主正对镜头半身中景，手持【瑜伽垫 / 健身器材 / 运动服】，自然地说：「【台词：在家也能练出好身材】」，边说边展示材质与做工；表情真诚有感染力，口型自然；背景是明亮的客厅 / 健身房，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【瑜伽垫 / 健身器材 / 运动服】在画面中央弹出并缓慢旋转，周围是礼盒、彩带和闪光粒子；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
