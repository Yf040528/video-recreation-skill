# 生鲜水果带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：超市买的水果不甜、不新鲜，咬一口皱眉，画面上方留出标题位置；3–8 秒：【水果 / 海鲜 / 肉类】登场，切开 / 剥开后咬一大口；8–12 秒：汁水丰富，人物满足地闭眼回味；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：切开瞬间汁水溢出、果肉纹理、水珠挂在表皮的慢镜头；随后依次展示三个卖点，每个约 3 秒：①产地与新鲜度 ②饱满的果肉 / 肉质 ③汁水与口感；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：普通水果干瘪不甜；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：现摘的新鲜饱满、汁水四溢；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在明亮的家庭厨房 / 果园 / 产地中，注重品质的家庭自然地切开 / 剥开后咬一大口，镜头从中景慢慢推近到【水果 / 海鲜 / 肉类】；切开时清脆的声音、汁水滴落；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【水果 / 海鲜 / 肉类】的包装，依次取出冷链泡沫箱、冰袋和整齐摆放的产品并整齐摆放；随后上手切开 / 剥开后咬一大口，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。注重品质的家庭形象的博主正对镜头半身中景，手持【水果 / 海鲜 / 肉类】，自然地说：「【台词：一口爆汁，产地直发的新鲜】」，边说边展示产地与新鲜度；表情真诚有感染力，口型自然；背景是明亮的家庭厨房 / 果园 / 产地，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【水果 / 海鲜 / 肉类】在画面中央弹出并缓慢旋转，周围是果篮、绿叶和水珠；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
