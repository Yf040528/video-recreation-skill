# 口播视频带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 正面口播讲解

```text
【人物描述】正对镜头，半身中景，坐在【背景，如简洁的书架前 / 明亮的工作室】；自然地开口说话，口型与语气自然，配合适度手势，表情亲切有感染力；说的内容：「【台词】」；固定机位，光线均匀柔和，背景轻微虚化。
```

## 2. 手持产品口播

```text
【人物描述】面向镜头，手里拿着【产品】，一边介绍一边把产品举到镜头前展示；说：「【台词，如这款……我用了一个月，最喜欢的是……】」；表情真诚，语速自然；中近景，明亮的室内光，背景干净。
```

## 3. 街头随拍口播

```text
【人物描述】走在【街道 / 商场】中，手持镜头视角跟随，人物边走边对镜头说：「【台词】」；表情轻松自然，偶尔看向周围；自然日光，轻微手持晃动，生活 vlog 质感。
```
