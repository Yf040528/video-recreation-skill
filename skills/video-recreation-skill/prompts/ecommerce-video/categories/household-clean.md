# 清洁用品带货短视频 AI 提示词模板

适用于 Seedance、可灵 Kling、万相 Wan、MiniMax 等图生视频 / 文生视频模型。【】里换成你自己的产品和人物；按 9:16 竖屏、15 秒以内设计。

> 在线一键使用（选模板 → 替换 → 生成视频）：[FrameFlow 无限画布](https://yimiagent.cn/answers/video-prompt-writing?utm_source=github&utm_medium=repo-prompts&utm_campaign=video-recreation-skill)

## 1. 痛点开场 · 解决

```text
9:16 竖屏，约 15 秒。0–3 秒：衣服上的污渍 / 灶台油污怎么都洗不掉，画面上方留出标题位置；3–8 秒：【洗衣液 / 洗洁精 / 清洁剂】登场，喷上 / 倒入产品，轻轻一擦 / 一洗；8–12 秒：污渍瞬间消失，焕然一新；12–15 秒：产品居中定格特写，人物满意点头。节奏快，真实生活光线，画面干净。
```

## 2. 卖点特写 · 质感

```text
9:16 竖屏，约 15 秒。开场微距：泡沫分解污渍的微距慢镜头；随后依次展示三个卖点，每个约 3 秒：①去污实测 ②气味与温和 ③用量省；镜头缓推、平移交替，浅色纯净背景，棚拍柔光，高级质感；结尾产品与 logo 居中定格。
```

## 3. 前后对比

```text
9:16 竖屏，约 12 秒。前半段：清洁前顽固污渍；一个干脆的转场（手从镜头前划过 / 闪白）；后半段：清洁后光亮如新（同机位对比）；最后 2 秒产品特写，人物竖起大拇指。同一机位、同一人物，对比清楚。
```

## 4. 场景种草

```text
9:16 竖屏，约 12 秒。在厨房灶台 / 洗衣房中，家庭主妇 / 租房党自然地喷上 / 倒入产品，轻轻一擦 / 一洗，镜头从中景慢慢推近到【洗衣液 / 洗洁精 / 清洁剂】；喷雾喷出的声音、擦拭的声音；暖色自然光，生活 vlog 质感，人物露出满意的表情。
```

## 5. 开箱上手

```text
9:16 竖屏，约 12 秒。俯拍桌面，一双手拆开【洗衣液 / 洗洁精 / 清洁剂】的包装，依次取出瓶身和替换装并整齐摆放；随后上手喷上 / 倒入产品，轻轻一擦 / 一洗，第一反应惊喜；明亮顶光，动作利落，节奏轻快。
```

## 6. 达人口播推荐

```text
9:16 竖屏，约 10 秒。家庭主妇 / 租房党形象的博主正对镜头半身中景，手持【洗衣液 / 洗洁精 / 清洁剂】，自然地说：「【台词：一喷一擦，十年油污都干净】」，边说边展示去污实测；表情真诚有感染力，口型自然；背景是厨房灶台 / 洗衣房，轻微虚化。
```

## 7. 限时促销

```text
9:16 竖屏，约 8 秒。【洗衣液 / 洗洁精 / 清洁剂】在画面中央弹出并缓慢旋转，周围是礼盒、彩带和闪光粒子；镜头快速推近再拉远，节奏紧凑有冲击力；人物从一侧出现快速拿起产品；色彩明亮饱和；最后 2 秒产品定格，画面上方留出价格 / 活动文字的位置。
```
